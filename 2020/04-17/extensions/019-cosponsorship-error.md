# COSPONSORSHIP ERROR

**Speaking:** Rogers, Mike D. (R000575) [R-AL]

**Measures:** H.R. 6494

```
                          COSPONSORSHIP ERROR

                                 ______
                                 

                            HON. MIKE ROGERS

                               of alabama

                    in the house of representatives

                         Friday, April 17, 2020

  Mr. ROGERS of Alabama. Madam Speaker, I rise today to inform the 
House that I plan to have my name removed as a cosponsor of H.R. 6494. 
The cosponsorship was made in error. The House is in a pro forma 
session due to the COVID-19 national emergency, so this request cannot 
currently be made in person. Since a Unanimous Consent request requires 
my presence, I will make said request when the House returns to 
session.

                          ____________________
```
