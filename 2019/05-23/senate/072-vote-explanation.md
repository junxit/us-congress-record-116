# VOTE EXPLANATION

**Speaking:** Durbin, Richard J. (D000563) [D-IL]

**Measures:** H.R. 2157

```
                            VOTE EXPLANATION

128 and number 129 due to the birth of my granddaughter, Josephine

substitute amendment, as well.
```
